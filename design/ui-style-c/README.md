# 天星教育 ERP · UI 样式稿（C 风格，客户与项目负责人已确认，2026-11-16）

六个独立的 HTML 文件，直接用浏览器打开即可，不依赖任何脚本。全部样式写在各元素的 style 属性里，
颜色、字号、圆角、间距的取值以这些文件为准。

| 文件 | 页面 |
| --- | --- |
| 01-login.html | 登录 |
| 02-today.html | 今日工作（首页） |
| 03-case-list.html | 案件列表 |
| 04-case-detail.html | 案件详情 |
| 05-school-list.html | 学校目录列表 |
| 06-school-detail.html | 学校详情（含编辑中的卡片与弱化的履历区） |

注意：
- 页面里的文字、姓名、数字全部是为展示风格而编的合成示意内容，不代表系统现有的数据或功能。
  实现时只呈现系统真实具备的内容，不得照抄示意数据。
- 导航条目用的是系统现有菜单名称；管理类条目收进「管理」一项。
- 这是样式参考，不是可直接复用的代码；实现应使用仓库的共用组件。
- 需要 Google Fonts 的 Noto Sans TC；离线时会回退到系统字体。
