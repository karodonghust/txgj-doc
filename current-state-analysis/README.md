## 这套文档回答什么

本目录只记录“已确认业务需求”和“当前代码”之间的差异，不创建新业务规则，也不代表功能已通过运行验收。

状态含义：

| 状态 | 含义 |
| --- | --- |
| `符合` | 当前代码与业务规则一致，并有足够证据支撑 |
| `部分符合` | 已有主要结构，但仍缺规则、入口或运行闭环 |
| `冲突` | 当前代码存在与业务基线相反的规则 |
| `缺失` | 未找到可执行实现 |
| `超范围残留` | 业务已排除，但代码、迁移或页面仍保留 |

验证层级必须分开理解：

```text
源码/迁移存在
  -> 自动化测试存在
  -> 本地运行验证
  -> 浏览器流程验证
  -> Vercel Preview 验证
  -> AWS 生产验证
```

前一层不能自动证明后一层。本轮是源码、迁移、路由和测试资产的静态现状分析；没有重新执行完整测试、浏览器测试、Vercel 或 AWS 验证。
